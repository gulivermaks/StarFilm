## Можливості

- **ШІ-підбір у 1 клік (Gemini BYOK):** опишіть настрій або сюжет вільною фразою, оберіть швидкі пресети (*«З друзями»*, *«Сімейний вечір»*, *«До 90 хв»*, *«У напрузі»*), тип контенту та виключені жанри.
- **Перевірка фактів у TMDB:** кожна рекомендація перевіряється через `TMDB /search/multi`, тому вигадані назви відсіюються, а картки одразу отримують локалізовані назви, рейтинги й постери.
- **Розумний пошук і деталі:** окрема вкладка пошуку в TMDB із фільтрами за типом, рейтингом і жанром, трейлерами на YouTube, описом, акторами та швидким запуском у мобільних плеєрах (*Stremio*, *Lampa*, *NUM*, *HDRezka*, браузер).
- **Власна бібліотека та профілі:** до 4 незалежних профілів на пристрої (*Головний* + родинні профілі, до 2000 записів у кожному), статуси (*Хочу подивитися*, *Дивлюся*, *Переглянуто*, *Не цікавить*), оцінки `1–10`, колекції й локальний офлайн-пошук на SQLite (Drift).
- **Безкоштовна хмарна синхронізація (Firebase Spark):** вхід через Google синхронізує профілі, бібліотеку, оцінки, колекції та фільтри смаку між вашими пристроями з по-польовим злиттям конфліктів (працює й повністю офлайн із чергою змін).
- **Інтеграція зі StarTV у домашній мережі (LAN):**
  - **Мій домашній ТВ** — запуск відео на приставці, двостороння синхронізація бібліотеки та передача ключів.
  - **Гостьовий ТВ** — лише запуск обраного фільму або трейлера без доступу до бібліотеки й ключів.
- **Резервні копії та OTA-оновлення:** експорт/імпорт JSON-бекапів (включно з імпортом бекапів StarTV) і перевірка нових версій прямо з GitHub Releases.

## Встановлення (Android)

1. Завантажте актуальний `StarFilm.apk` зі сторінки [**Releases**](https://github.com/gulivermaks/StarFilm/releases/latest).
2. Встановіть APK на смартфон (Android 8.0+).
3. На першому запуску (або в **Налаштуваннях**) вкажіть власні безкоштовні ключі:
   - **TMDB API Key** (v3 Key або v4 Read Access Token) — [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)
   - **Gemini API Key** (опціонально, для ШІ-підбору; без нього працює fallback через `TMDB /discover`) — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. Особисті ключі зберігаються **лише локально** в зашифрованому сховищі Android Keystore і ніколи не передаються до Firebase.

## Архітектура та технології

- **Flutter / Dart** + **Riverpod**
- **Локальна БД:** `Drift` (SQLite)
- **Безпечне сховище:** `flutter_secure_storage` (Android Keystore)
- **Хмара:** Firebase Auth (Google Sign-In) + Cloud Firestore (план Spark, без серверних платних функцій)
- **Мережа:** строгий `LanGuard` (HTTP дозволено лише в приватних підмережах RFC1918 для StarTV; назовні — лише HTTPS) та `LogSanitizer` (маскування ключів, токенів і PIN-кодів у діагностиці)

Для локальної збірки підготуйте власні `android/app/google-services.json` та `android/key.properties` (вони виключені з Git через `.gitignore`), а також див. [StarFilm_FIREBASE_FREE_SETUP.md](StarFilm_FIREBASE_FREE_SETUP.md).

```powershell
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter test
./tools/build_apk.ps1
```
