## Можливості

- **ШІ-підбір у 1 клік (Gemini BYOK):** опишіть настрій або сюжет вільною фразою або голосом, оберіть швидкі пресети (*«З друзями»*, *«Сімейний вечір»*, *«До 90 хв»*, *«У напрузі»*, *«На реальних подіях»*), тип контенту та виключені жанри (19 стандартних жанрів TMDB).
- **Перевірка фактів у TMDB:** кожна рекомендація перевіряється через `TMDB /search/multi`, тож вигадані назви відсіюються, а картки одразу отримують локалізовані назви, рейтинги, постери й тривалість.
- **Рейтинги КП та IMDb (опціонально):** за наявності особистого безкоштовного ключа *Kinopoisk Unofficial* у картках показуються оцінки Кінопошуку та IMDb.
- **Розумний пошук і деталі:** окрема вкладка пошуку в TMDB із фільтрами за типом, роком і жанром, трейлерами на YouTube, акторами, країнами та швидким запуском у мобільних плеєрах (*Stremio*, *Lampa*, *NUM*, *HDRezka*, *VLC*, *MX Player*, *Kodi*, *TorrServe*, браузер).
- **Власна бібліотека та профілі:** до 4 незалежних профілів на пристрої (*Головний* + родинні профілі, до 2000 записів у кожному), вкладки *Хочу подивитися*, *Дивлюся*, *Переглянуто*, *Колекції* та *Приховані / Інше*, оцінки `1–10`, локальний офлайн-пошук на SQLite (Drift), імпорт CSV/TSV та сповіщення про цифрові релізи фільмів.
- **Безкоштовна хмарна синхронізація (Firebase Spark):** вхід через Google інкрементально синхронізує профілі, бібліотеку, оцінки, колекції та фільтри смаку між вашими пристроями з по-польовим злиттям конфліктів (працює й повністю офлайн із чергою змін).
- **Інтеграція зі StarTV у домашній мережі (LAN):** сканування QR-коду камерою або ручне підключення за `IP:порт` та PIN-кодом:
  - **Мій домашній ТВ** — запуск відео або трейлера у вибраному плеєрі ТВ, двостороння синхронізація бібліотеки й профілів, автоматичне оновлення списку доступних плеєрів та передача API-ключів.
  - **Гостьовий ТВ** — лише запуск обраного фільму або трейлера без доступу до бібліотеки й ключів.
- **Резервні копії та OTA-оновлення:** експорт/імпорт JSON-бекапів (включно з імпортом бекапів StarTV), вбудоване завантаження й перевірка `SHA-256` та підпису нових версій прямо з GitHub Releases.

## Встановлення (Android)

1. Завантажте актуальний `StarFilm.apk` зі сторінки [**Releases**](https://github.com/gulivermaks/StarFilm/releases/latest).
2. Встановіть APK на смартфон (Android 8.0+).
3. На першому запуску (або в **Налаштуваннях**) вкажіть власні безкоштовні ключі:
   - **TMDB API Key** (v3 Key або v4 Read Access Token) — [themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)
   - **Gemini API Key** (опціонально, для ШІ-підбору; без нього працює fallback через `TMDB /discover`) — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   - **Kinopoisk Unofficial Key** (опціонально, для рейтингів КП/IMDb) — [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/)
4. Особисті ключі зберігаються **лише локально** в зашифрованому сховищі Android Keystore і ніколи не передаються до Firebase.

## Архітектура та технології

- **Flutter / Dart** + **Riverpod**
- **Локальна БД:** `Drift` (SQLite)
- **Безпечне сховище:** `flutter_secure_storage` (Android Keystore)
- **Хмара:** Firebase Auth (Google Sign-In) + Cloud Firestore (план Spark, без серверних платних функцій)
- **Мережа:** строгий `LanGuard` (HTTP дозволено лише в приватних підмережах RFC1918 для StarTV; назовні — лише HTTPS) та `LogSanitizer` (маскування ключів, токенів і PIN-кодів у діагностиці)
